## Mandatory User Acceptance Scenarios

### Replenishment

An Inventory Analyst must be able to identify which products require action at a selected site and understand the recommended quantity.

### Supplier Performance

A Procurement Manager must be able to identify suppliers with delivery, lead-time or quality issues.

### Refresh

A valid source update must be processed through the documented refresh workflow without manual copy/paste.

### Data Quality Failure

A critical data-quality problem must be visible before results are treated as reliable.
